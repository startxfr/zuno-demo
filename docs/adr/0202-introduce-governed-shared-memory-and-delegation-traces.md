# ADR-0202: Introduce governed shared memory and delegation traces

- **Status:** Proposed
- **Target:** v2
- **Date:** 2026-08-04

## Context

Tekos/Arkos may share validated knowledge, while commercial/finance conversations remain user-isolated.

## Decision

Provide explicit promoted shared knowledge and visible delegation traces without turning private raw conversations into shared memory.

## Alternatives considered

Global conversation memory.

## Consequences

Improves reuse without collapsing privacy boundaries.

## Security considerations

Promotion requires provenance, authorization, and review rules.

## Operational considerations

Memory lifecycle becomes an operated capability.

## Migration / evolution

v3 may automate safe knowledge promotion.
