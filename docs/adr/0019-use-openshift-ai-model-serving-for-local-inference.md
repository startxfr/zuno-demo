# ADR-0019: Use OpenShift AI model serving for local inference

- **Status:** Implemented
- **Target:** v0
- **Date:** 2026-08-04
- **Decision owners:** Zuno Demo architecture team

## Decision

Serve approved local Granite, Qwen and Llama variants through OpenShift AI model-serving capabilities on NVIDIA L4 GPUs.

See [Standard clauses](README.md#standard-clauses) for Context, Alternatives, Consequences, Security/Operational considerations, Migration/evolution and Related ADRs.
