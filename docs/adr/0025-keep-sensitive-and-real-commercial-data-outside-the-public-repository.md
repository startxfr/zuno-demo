# ADR-0025: Keep sensitive and real commercial data outside the public repository

- **Status:** Implemented
- **Target:** v0
- **Date:** 2026-08-04
- **Decision owners:** Zuno Demo architecture team

## Decision

Commit only anonymized or synthetic business fixtures; never commit real SXA records or nominative data.

See [Standard clauses](README.md#standard-clauses) for Context, Alternatives, Consequences, Security/Operational considerations, Migration/evolution and Related ADRs.
