# ADR-0020: Support both local and external LLM providers

- **Status:** Implemented
- **Target:** v0
- **Date:** 2026-08-04
- **Decision owners:** Zuno Demo architecture team

## Decision

Allow local models plus OpenAI, Gemini, Anthropic and Mistral under routing and classification policy.

See [Standard clauses](README.md#standard-clauses) for Context, Alternatives, Consequences, Security/Operational considerations, Migration/evolution and Related ADRs.
