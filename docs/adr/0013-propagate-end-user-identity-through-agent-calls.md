# ADR-0013: Propagate end-user identity through agent calls

- **Status:** Implemented
- **Target:** v0
- **Date:** 2026-08-04
- **Decision owners:** Zuno Demo architecture team

## Decision

Preserve user identity from frontend through BFF/runtime to controlled downstream integrations whenever supported.

See [Standard clauses](README.md#standard-clauses) for Context, Alternatives, Consequences, Security/Operational considerations, Migration/evolution and Related ADRs.
