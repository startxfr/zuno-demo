# ADR-0006: Extend OKF with Zuno agent-specific metadata

- **Status:** Implemented
- **Target:** v0
- **Date:** 2026-08-04
- **Decision owners:** Zuno Demo architecture team

## Decision

Define a Zuno profile for runtime concerns not prescribed by OKF, including tasks, models, tools, policies, permissions and UI metadata.

See [Standard clauses](README.md#standard-clauses) for Context, Alternatives, Consequences, Security/Operational considerations, Migration/evolution and Related ADRs.
