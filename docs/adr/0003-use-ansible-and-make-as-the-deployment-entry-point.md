# ADR-0003: Use Ansible and Make as the deployment entry point

- **Status:** Implemented
- **Target:** v0
- **Date:** 2026-08-04
- **Decision owners:** Zuno Demo architecture team

## Decision

Expose stable Make targets and delegate environment checks, preparation, configuration, installation and validation to Ansible.

See [Standard clauses](README.md#standard-clauses) for Context, Alternatives, Consequences, Security/Operational considerations, Migration/evolution and Related ADRs.
