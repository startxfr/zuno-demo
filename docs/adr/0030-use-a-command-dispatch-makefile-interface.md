# ADR-0030: Use a command-dispatch Makefile interface

- **Status:** Implemented
- **Target:** v0
- **Date:** 2026-08-04
- **Decision owners:** Zuno Demo architecture team

## Decision

Support commands such as make precheck keycloak while mapping the second target token to a component/scope dispatcher.

See [Standard clauses](README.md#standard-clauses) for Context, Alternatives, Consequences, Security/Operational considerations, Migration/evolution and Related ADRs.
