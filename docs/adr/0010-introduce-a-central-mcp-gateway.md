# ADR-0010: Introduce a central MCP Gateway

- **Status:** Implemented
- **Target:** v0
- **Date:** 2026-08-04
- **Decision owners:** Zuno Demo architecture team

## Decision

Route all MCP tool access through a shared gateway to centralize discovery, authorization, policy enforcement and observability.

See [Standard clauses](README.md#standard-clauses) for Context, Alternatives, Consequences, Security/Operational considerations, Migration/evolution and Related ADRs.
