# ADR-0021: Route models according to C1 C2 C3 classification

- **Status:** Implemented
- **Target:** v0
- **Date:** 2026-08-04
- **Decision owners:** Zuno Demo architecture team

## Decision

Allow SaaS for C1, restricted SaaS for C2 and local-only inference for C3.
