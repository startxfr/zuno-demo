# ADR-0028: Require a seventy-five percent evaluation threshold

- **Status:** Implemented
- **Target:** v0
- **Date:** 2026-08-04
- **Decision owners:** Zuno Demo architecture team

## Decision

Use 75 percent as the initial release-quality target and evolve toward automated quality gates.
