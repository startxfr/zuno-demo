# Agent Catalog

Last reviewed: 2026-11-19

The agent definitions are not in this repository. They live in
[startxfr/zuno-demo-agents](https://github.com/startxfr/zuno-demo-agents) as OKF bundles
([ADR-0576](../adr/0576-extract-agent-definitions-and-corp-policies-into-the-zuno-demo-agents-repository.md)), are signed and pinned by one
digest in `platform/okf/agents.lock`, and are served by UnifAI ([ADR-0561](../adr/0561-adopt-unifai-as-the-agent-platform.md)). The pages in
this directory describe what each agent is for and point to its definition; the platform side is in
[agents release integration](../platform/agents-release-integration.md) and
[agent platform architecture](../architecture/agent-platform-architecture.md).
